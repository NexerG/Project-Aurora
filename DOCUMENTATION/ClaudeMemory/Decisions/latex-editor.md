# Decision — LaTeX editing is native: `.tex` opens in the note editor, a C# TeX expander sits under a future interpreter

**Date:** 2026-10-05
**Scope:** `ArctisAurora.Core.UI` — `TexSourceFormat`, `RichTextDocument`, `DocumentEditorControl`, `SyntaxTokenizer`, `SyntaxState`; `ArctisAurora.Core.Tex` — `TexExpander`, `TexReader`, `TexToken`, `TexCatcode`, `TexError`, `TexTypesetter`, `TexNode` and its subtypes, `TexParStyle`, `TexFormat`, `TexHyphenator`, `TexGlue`, `TexFont`, `TexStyle`, `ITexFontMetrics`; `ArctisAurora.Core.UI` — `TexLowering`, `TexAtlasMetrics`, `MathLayout`, `TextRunControl`, `BlockControl`, `TableControl`, `DocumentXml`, `TextMeasurer`; `ArctisAurora.Core.Filing` — `CffOutlines`, `AuroraFont`; `ArctisAurora.Core.Filing.Serialization` — `AssetImporter`

**Status: PARTIAL** — L1 (file + source editor + expander) L2 (CFF import + Latin Modern atlases) and L3 (typesetter + lowering to `<Document>`) landed 2026-10-05; L4 (split view) and L5 (floats, `tabular`, `\label`/`\ref`, BibTeX) landed 2026-10-06; L6 (amsmath natively, shared with notes math M5) landed 2026-10-06; L7 was split into L7a–L7g (user-approved 2026-10-06) and L7a (Knuth-Plass line breaking, justify shrink, justify before a display) and L7b (soft hyphen U+00AD, hyphenation) landed 2026-10-06; L7c (glue gaps: first-line indent, space above, spacer runs, TeX vertical glue, display skips) landed 2026-10-06; L7d (pages: page breaks, running heads and feet, marks, `\pageref`) and L7e (real footnotes) and L7f (float placement) landed 2026-10-06; L7g (exact table rules, centred tables, width-aware align/flalign/multline) landed 2026-10-06; L8 (in-house PDF export) landed 2026-10-07. Plan: [../Context/tex-plan.md](../Context/tex-plan.md).

## What changed
- `.tex` files open in the note editor as LaTeX source: `TexSourceFormat.Read(text, name)` → `<Document>` of `<Block StylingType="Code" Language="latex" Wrap="true">`, one per line (one trailing `\r` stripped per line); `Write(document, newline)` is the inverse.
- `RichTextDocument`: `.tex` in `extensions`; fields `sourceNewline` (`"\r\n"` if the file contains CRLF, else `"\n"`) and `sourceBom`; private `TexSource(path)` reads bytes and detects a UTF-8 BOM; `Save` writes `.tex` with `new UTF8Encoding(sourceBom)` — a save is byte-identical.
- `DocumentEditorControl.LoadDocument`: `.tex` sets `document.layout.page = new PageLayout { mode = PageMode.Pageless }`; `content.plainText` is true for `.txt` and `.tex` (Markdown shortcuts off).
- `SyntaxTokenizer`: `Mode.Latex` for language `tex`/`latex` (`Latex`, `ControlEnd`, `units` set); `SyntaxState.TexMath` new member.
	- Control sequences → Keyword; `%` to end of line → Comment (not `\%`).
	- Math `$…$`, `$$…$$`, `\(…\)`, `\[…\]` → String; `TexMath` carries across lines and closes on the next `$`, `\)` or `\]`.
	- Numbers not preceded by a letter, plus a TeX unit (`pt pc in cm mm bp dd cc sp em ex mu fil fill filll`) → Number.
- Thorium `VaultBrowserControl` unchanged: `Accepts` reads `RichTextDocument.extensions`, `BuildTab` takes any note path.
- New namespace `ArctisAurora.Core.Tex`, pure CPU, nothing in the UI calls it yet:
	- `TexCatcode` — the 16 categories in `\catcode` order. `TexToken` (readonly struct) — `name` (control sequence) or `ch` + `cat`, `param` (1–9 body slot), `line`, `column`. `TexError` — line, column, message.
	- `TexReader` (internal) — TeX's mouth: lines split on `\n`, trailing spaces cut, `\r` end-of-line char appended; states NewLine/MidLine/SkipBlanks; a control word skips spaces after it; a blank line is `\par`; `%` drops the rest of the line; categories are read live, so `\catcode` takes effect mid-line.
	- `TexExpander(string source)`, `errors`, `Next(out TexToken)` — returns the next unexpandable token for a typesetter (characters, `{`/`}` after their group is opened/closed, `\relax`, `\par`).
- Expander coverage:
	- Groups and save stack with TeX's global/local level rule (a global change survives the group's restore); `\global`, `\long`; `\begingroup`/`\endgroup`.
	- `\def \gdef \edef \xdef` with delimited parameters and brace stripping; `\let`, `\futurelet`; `\expandafter`, `\noexpand`, `\csname`/`\endcsname`, `\string`, `\the`.
	- `\if \ifx \ifcat \ifnum \ifdim \ifodd \ifcase \iftrue \iffalse \ifdefined \ifcsname \else \or \fi`.
	- Count/dimen/skip/toks registers, `\chardef \countdef \dimendef \skipdef \toksdef`, `\advance \multiply \divide`, `\catcode`.
	- Numbers by tex.web's scan_int (`'` octal, `"` hex, `` ` `` char code); dimensions by tex.web's scan_dimen arithmetic in scaled points (round_decimals, xn_over_d, units `pt in pc cm mm bp dd cc sp true`, internal quantities as units, `fil`/`fill`/`filll` in glue); `\the` prints via print_scaled. `em` = 10pt and `ex` = 4.30554pt (cmr10), fixed unless `quad`/`xHeight` are set (L3).
	- LaTeX level natively: `\newcommand`/`\renewcommand`/`\providecommand` (star = not long, `[n][default]`), `\newenvironment`/`\renewenvironment`, `\begin`/`\end` (an environment group; mismatched `\end` reported LaTeX-style), `\makeatletter`/`\makeatother`, `\@ifnextchar`, `\@ifstar`, `\newif`, `\newcounter` (global, registers from 256; `[within]` resets x, cascading, when within steps — L3), `\setcounter`, `\addtocounter`, `\value`.
- Errors are collected, never thrown. Recovery is TeX-style: undefined cs skipped, runaway argument stops at `\par` for non-long, a missing `}` reported at end of file, open groups/conditionals reported at end. 1,000,000 expansion steps or input-stack depth 10,000 halts the run with an error.

## Why these choices

**The whole LaTeX editor is native, not a port of tex.web.** (agreed with the user 2026-10-05)
A full port (TRIP-verified, XeTeX-compatible, running the real `latex.ltx` and package `.sty` sources, Aurora only rendering shipped pages) was considered and rejected by the user. It would run any package's source but costs the port's T3–T5 (~25k lines of WEB) before anything shows; native gets the user's documents sooner and reuses Aurora's runs, `TextMeasurer`, `Paginate` and math. Cost accepted: support is bounded by what we reimplement — every package environment (amsmath `align` two-pass, `tabular`, …) is C#, and a package we have not rewritten (e.g. `mathtools` patching amsmath internals) does not work. The analysis behind the choice: Aurora's typesetting cannot run TeX macro code that reads layout mid-expansion (`\lastskip`, `\wd` of a just-built box, `\pagetotal`, `\output`), because `DocumentControl.Paginate` is a post-measure placement pass and `TextLine` is float geometry with no glue. The drawing layer is reusable either way.

**L-F1: no NuGet, no external tools.** `\usepackage` is accepted; unknown packages are logged and ignored. Package set is "as many as possible" (user), starting from amsmath, amssymb, graphicx, xcolor, hyperref (links), geometry, booktabs, enumitem, fancyhdr and growing.

**L-F2 level 2: a real TeX tokenizer + expander, document commands and package environments as C# primitives.**
Rejected level 1 (a command table with template `\newcommand`): it breaks on `\def\foo#1.#2`, `\expandafter`, `\newif` and `\makeatletter` code.

**L3 emits a TeX-like node list (chars, glue, kerns, penalties, boxes), lowered to `<Document>` afterwards.** (user: "your recommendation")
It keeps `\hbox`/`\setbox`/`\wd`, `\vskip`, `\lastskip`/`\unskip`/`\lastbox` addable later; emitting straight to `<Document>` closes them. `\output` and the page-builder primitives stay out — that is the port route.

**L-F3 / L-F4 / L-F5 / L-F6.** Overleaf-style split view (source + read-only paged preview). The preview is the `<Document>` tree, Aurora's layout gaining glue gaps, a Knuth-Plass mode, hyphenation, footnotes, running heads and float placement in L7. CFF (Type 2 charstrings) font support is added — the atlas baker already takes cubic `Bezier` contours (`SvgPath` feeds cubics to the MTSDF generator), so the work is the CFF table reader. Endnotes in v1, real footnotes in L7. Superseded by L7e (2026-10-06): real footnotes at the page foot; the endnote section is gone.

**The file/editor and the expander were planned as two phases and merged into L1** (user).

**`.tex` reuses `DocumentEditorControl` instead of a new editor control, each source line a Code block.** Undo, selection, clipboard and code colouring come with it.

**Line ending and BOM live on `RichTextDocument`**, so a save is byte-identical; precedent `SheetDocument.csvBom`. `.txt` is deliberately not changed.

**The expander has its own namespace `ArctisAurora.Core.Tex`** (pure, no UI dependency) rather than sitting flat in `Core.UI` like `MathParser`.

**Meanings are nested private types inside `TexExpander`** (Primitive/Macro/CharMeaning/Register) with one generic save-stack `Table<TKey,TValue>` for meanings, catcodes and registers. `\begin`/`\end` close the environment group through an internal sentinel control sequence pushed after `\end<name>`'s code.

**`DocumentControl.EndCodeBlock` is off in `plainText`** (user, 2026-10-05): Enter on an empty last code line would turn it into text, so a `.tex` would lose its LaTeX lines while typing at the end. `Tex.SourceEnterPaste` covers it.

**`.tex` shares the `.txt` refusals** (user, 2026-10-05) — `DocumentEditorControl.CanAlign`, `InsertTable`, `PasteImage`: a table, picture or alignment has nowhere to go in source. No test.

**Latin Modern ships as a baked atlas only** (user, 2026-10-05) — SUPERSEDED by L8-F2 (2026-10-07): the `.otf` files are now committed beside their atlases in Thorium's `Data/Fonts` because the PDF export draws from the outlines. Originally: the `.otf` files are downloaded to bake from, not committed and not needed on users' machines; the atlas is what the repo carries.
Fonts bake only in Debug (`AssetImporter`: `if (!Engine.isDebug) return true;`), and a Debug machine without the source logs a Warn and keeps the committed atlas, so committing just the atlas already works. Rejected: committing the `.otf` files (users do not need them) — reversed by L8-F2.

**Sources live in gitignored `_Build/FontSources/`, probed after the system font folders.** Rejected: copying into the per-user Windows font folder (writes into the OS font directory); an absolute path in the import XML (machine-specific).

**Latin Modern is imported by Thorium only (`ThoriumFonts.imports.xml`).** Atlases are baked per host into each host's own `Data/Fonts` (Thorium, Carbon and AuroraEditor each track their own `cambria/`), so engine imports would bake and commit three copies. Only Thorium edits `.tex`.

**The `Latex` charset is 348 chars, including the ligatures and the accent, quote and dash characters**, so L3's TeX ligatures (`` `` `` → “, `--` → –, fi, ffi …) and accents need no re-bake. Rejected: the existing `Latin` charset.

**Faces: Roman 10 ×4 (regular, italic, bold, bold-italic), Mono 10, LM Math with Roman italic/bold for variables** (same pattern as Cambria). Optical sizes (5–17) and Sans are left out — the 10pt master is scaled.

**The ink box uses exact cubic extrema**, not the control-point hull, which is looser.

**CFF needed no atlas-side work.** Cubic `Bezier.Point.isCubicControl` already existed (made for SVG icons), the MTSDF generator fills by nonzero scanline winding so CFF's counter-clockwise outer contours need no reversal, and the sfnt table directory reader already handles `OTTO`.

**`importerVersion` is deliberately not bumped** — existing atlases do not re-bake.

**Empty-glyph fix** (user approved). The old check treated `glyphHeight == 1` / `glyphWidth == 1` (the `Glyph()` placeholder) as "empty"; LM Math's ∑ (−250…750) and √ (−960…40) are exactly 1000 units = 1 em tall, got squashed to 0.1 em and drew as a few dots. Cambria's never hit it. Now "empty" means no contours. Existing atlases are unchanged until re-baked; empty glyphs (spaces) behave as before.

Measured: the whole bake took ~40 s for ~2,600 cells (Roman 24 s, Mono 4 s, Math ~10 s), far below the ~20 min estimated from Cambria's ~7 min first-launch note; that note in `math-in-notes` may refer to something else and was not re-measured.

- F1 — LaTeX commands that are plain macros live in a TeX prelude, a C# string in `TexFormat`, run before the source. Rejected: every command as a C# primitive (more code, loses LaTeX's own structure); a data file `Data/Tex/aurora.ltx` (path plumbing into three hosts, not XML).

**A C# primitive or a prelude macro: anything `MathParser` also knows (`\,`, `\quad`, `\ldots`, `\{`) must be a caller primitive.** Inside math the typesetter writes tokens back as source with expansion on, so a macro would expand to `\kern…` and break the formula. Text symbols, accents and spacing are therefore C# tables in `TexTypesetter`.

**Math is collected as source text with `passUndefined` on.** User macros expand and unknown commands (`\frac`, `\alpha`) pass through to `MathParser`; a control word gets a trailing space. `\par`, an `\end…` or an internal `@end…` sentinel inside math ends it with "Missing $ inserted".

**Typesetter state is saved through the expander's save stack via `Save(Action)`**, so `{\bf x}` and environments restore as TeX does. Headings and footnotes suspend/resume the outer state through an internal frame stack, ended by sentinels `\@endhead`, `\@endnote`; `\@runin` (run-in `\paragraph`) and `\@label` (`\item[x]`) skip the following space. Alignment is taken when a paragraph ends (TeX's rule), so `{\centering text\par}` centres and `{\centering text}` does not.

**Ligatures live in the typesetter, Roman/Sans only:** `` `` `` → “, `''` → ”, ` → ‘, ' → ’, `--` → –, `---` → —, `!``/`?`` → ¡/¿, ff fi fl ffi ffl → U+FB00–FB04; braces break a ligature; none in mono. **Accents compose with Unicode NFC** (base + combining mark); `\i`/`\j` as accent bases become i/j; an accent over nothing gives the spacing accent; no precomposed form → base letter + Warn.

**A fragment with no `\documentclass` is typeset as a body** (lenient; tests use fragments). Text in the preamble is "Missing \begin{document}" once. Nothing after `\end{document}` is read.

**Fork A (after the first golden; user: hand to a subagent, recommended option).** LM Math's italic face is LM Roman Italic, which has no Greek, so `\pi` (`MathParser` sets Greek italic) drew blank. `MathLayout.Present` uses Regular when the requested face's ink box is empty (0,0,0,0 — how a face missing a character bakes, checked for π/α in LM Math Italic and Bold) and Regular's is not; Greek in LM Math is therefore upright, not italic as in LaTeX. Rejected: LM Math's italic Greek at U+1D6FC+ (outside the 16-bit char atlas — large change); reverting F2. Cambria is unaffected (its italic has Greek); all existing note-math goldens pass.

**L5-F1 (user rejected both first options, then took this): references resolve after the run, in one pass.**
`\ref`/`\cite` leave `TexRefNode`s carrying their style; `\bibliography` leaves a mark; after `\end{document}` the cited entries are formatted (BibTeX's job) into thebibliography source, inserted via `InsertSource` and typeset into a list spliced at the mark; `Resolve()` then fills every node's text. Rejected: (a) two passes like LaTeX's `.aux` — doubles the cost of every 0.5 s recompile; (b) placeholder nodes resolved in lowering with the bibliography where it stands — the bibliography sees only earlier citations; (c) carrying the aux across recompiles (latexmk-style) — refs lag a compile and depend on history. Cost accepted: a `\ref`'s text cannot be tested by `\ifx`/`\ifnum` during expansion (hyperref's `\ref` has the same limit). A `\ref` inside math is rewritten to `\text{…}` in the math source at resolve.

**L5-F2: a `Borders` flag on `<Table>`.**
A LaTeX table gets the full Aurora grid if its spec has `|` or its body has `\hline`/`\cline`/booktabs rules; otherwise no borders. Rejected: always the grid (no engine change, but wrong for borderless tables); exact per-edge rules (`|` per column, a rule per row, booktabs weights) — a large `TableControl` change, L7-sized. **L5-F3: column widths are the natural width measured in lowering.**

Rejected: splitting the text width evenly.

**L5-F4 (user: real spans, scope iii): column spans in note tables.**
Rows are stored short (no placeholder cells) and cells are found by grid position. Structural edits are span-aware: inserting a column inside a span widens it, deleting a column inside a span shrinks it. Merge/split form (user picked the recommended one): "Merge cell right" — the caret's cell absorbs the next cell in its row, blocks appended, an empty side dropped, refused on a row's last cell; "Split cell" — a merged cell back to single cells, content in the first, refused on a single cell. Both undoable as one table edit. Rejected: merge by selection range; display-only spans with structural edits refused. Row spans (`\multirow`) not done.

**L5-F5: equation numbers stay with L6 — done in L6 (2026-10-06).** `\label` inside math is stripped (it used to leak into `MathParser`); `\eqref` was a "(??)" placeholder until L6, which numbers equations and resolves it (see L6 below).

**L5-F6: BibTeX styles plain, unsrt, abbrv, alpha.**
The 14 standard entry types following plain.bst's blocks; `@string`, `#` concatenation, month macros, `@comment`, `@preamble` skipped; names "First von Last", "von Last, First", "von Last, Jr, First", "and others" → "et al.". Rejected: plain only.

**L6-F1: environments that depend on the line width are set without it.**
Layout does not know the line width. `align` and `flalign` are spaced like `aligned`, with `\minalignsep` (1 em) between pairs. `multline`'s first row is flush left and its last row flush right within its widest row plus a 1 em `\multlinegap`; middle rows are centred. Rejected: passing the column width into `MathLayout.Layout` and the box cache key — exact amsmath spacing, but the formula is re-laid out on every width change (resizing) and the cache grows per width. Revisited in L7g-F4 and L7g-F5: top-level `align`/`flalign`/`multline` are now width-aware.

**L6-F2: a tag that collides with its formula shifts the formula.**
The formula moves left to keep 1 em clear of the tag, and overflows past that (`TextRunControl.MathLeft`). Rejected: LaTeX's tag on its own line, which needs the width (goes with F1's rejected option).

**L6-F3: math environments reach `MathParser` as source the typesetter writes back.**
The names are expander primitives and `Append` writes them back as `\begin{…}`/`\end{…}` source. Rejected: a flag on the expander so `\begin`/`\end` pass through as tokens while math is collected, which would touch the expander's group bookkeeping.

**L6-F4: scope is environments plus the small amsmath commands.**
Environments, `\binom`/`\dbinom`/`\tbinom`, `\operatorname(*)`, `\DeclareMathOperator` (as a prelude macro), `\overset`/`\underset`, `\boxed`; `\iint`/`\iiint` already existed. Rejected: environments only.

**L6: equation numbering is source rewriting.**
The typesetter splits the collected body into rows at top-level `\\` (outside braces and nested `\begin…\end`). Each numbered row gets an injected `\tag{n}`, and its `\label` maps to n, or to the tag's text when a `\tag` is present. `equation` and `multline` take one number, `multline`'s on the last row. `\notag`/`\nonumber` and empty rows are not numbered. Numbers are `n` in article and `chapter.n` in report/book, like figures. The body is wrapped in `\begin{env}…\end{env}`, except `equation`. `MathParser` therefore never auto-numbers, so notes do not number either (as in Obsidian; only `\tag` shows).

**L7b-F1: soft hyphens are inserted by a pre-pass in `TexLowering.Lower` (agreed in the L7 split).**
The pre-pass inserts U+00AD character nodes into paragraph lists, top level only, so `\mbox`/`\hbox` contents are never hyphenated. Rejected: hyphenating inside Aurora's measurer (would hyphenate notes and needs a language per note); in the typesetter.

**L7b-F2: pattern source is TeX Live's hyph-en-us from CTAN, converted to XML (user picked A).**
Lines break where LaTeX breaks them. The data is a generated file copied into the repo as a new file; the download (~31 KB + <1 KB) was user-approved. Rejected: B, generating our own patterns with a C# PATGEN port over the public-domain Moby Hyphenation List (~1.5 MB download, a larger slice, breaks some words differently from LaTeX); C, a rule-based hyphenator with no download (wrong breaks TeX would not make).

**L7b: word rules are TeX-like.**
A word is a run of letters in one style, not monospaced (TeX's `\hyphenchar` -1 for tt). Letters a-z, capitals lowered, ligatures ﬀ ﬁ ﬂ ﬃ ﬄ taken apart for lookup with no break inside a ligature. A word holding any other letter (é, ï) or already holding a `\-` is left as written. Minimums 2 and 3 come from the file and apply to exceptions too. `\hyphenation` beats the file's exceptions, which beat patterns. Headings are hyphenated as in LaTeX; code is not.

**L7b: U+00AD is general in Aurora.**
Any soft hyphen in a note now behaves the same way: break opportunity, hyphen at a line end, dropped on copy.

**L7b: Knuth-Plass hyphen costs are TeX plain's.**
`\hyphenpenalty` 50 added as p² to demerits, `\doublehyphendemerits` 10000 for consecutive hyphenated lines, `\finalhyphendemerits` 5000 when the second-last line is hyphenated.

**L7c-F1: indent and space above are a full note feature (user picked it over "layout + XML only").**
`Indent`/`SpaceBefore` are carried through Enter (a split: the tail keeps both, Word-like), Backspace/merge (`TakeKind`), undo snapshots and plain-text/fragment paste, like `alignment`. No UI sets them. Rejected: honoured in layout and XML only, lost on edits.

**L7c-F2: display skips split the paragraph (user).**
Lowering splits a paragraph at each display formula into text / display / text blocks: `\abovedisplayskip` above the display and `\belowdisplayskip` above the continuation, which is never indented. This is TeX's model (the text either side is broken separately) and needs nothing new in Aurora. Short display skips are not used. Rejected: padding the display line's box inside one block (caret and selection on that line would grow).

**L7c-F3: exact horizontal gaps are a spacer run (user).**
Rejected: keeping the NBSP approximation.

**L7c-F3b: a spacer is a fixed-width NBSP whose span sets its advance, `<Run Text=" " Space="px"/>` (user, after implementation started).**
A U+FFFC object character was the first proposal. Least plumbing: `.md`/`.txt` just get an NBSP, and caret and selection work unchanged. Cost: a spacer is never a line break (TeX can break at `\quad`/`\hspace`). Rejected: an object character (breakable, but needs object handling in caret, typing and the writers).

**L7c: vertical glue is natural widths only.**
No stretch or shrink, so no `\flushbottom` page filling. Structural skips (sections, lists, verbatim, quote/center; a float's `\intextsep`/`\floatsep`/`\textfloatsep` are `<Page>` attributes placed by `Paginate` since L7f) combine by max like `\addvspace`; `\vskip`/`\vspace`/`\bigskip` add. Space above a block at a page top is dropped by pagination (the block starts at the page top).

**L7c: indent rules.**
A paragraph is indented by `\parindent` (15/17/18pt) unless `\noindent`, right after a heading (until text), right after a list/trivlist environment or float until a blank line, inside a list or quote, or not justified (centred/flush/ragged paragraphs, LaTeX's `\parindent` 0 there); `\bibitem` entries never.

**L7c: list skips and `BlockSpacing`.**
`\topsep` above and below, `\itemsep + \parsep` between items, `\parsep` between paragraphs of one item; second level half, deeper a quarter (approximates `\@listii`/`\@listiii`). `BlockSpacing` is 0 for LaTeX documents, which is `\parskip` 0pt.

**L7-F1: page breaks, page styles, marks, footnotes and floats are a full note feature, carried through edits (user, 2026-10-06, against the recommendation).**
Rejected (the recommendation): layout + XML only — honoured on read, write and layout, not carried through Enter or merge, since the LaTeX preview is read-only. `BlockSnapshot`, `Restore` and `TakeKind` copy every one of the new fields. No UI creates any of them.

**L7-F1 edit rules (user, asked mid-implementation).**
Enter splits by kind. A page break, `\thispagestyle` and marks stay with the head only: they belong to the block's start, and the literal L7c rule "the tail keeps everything" would give two page breaks. Footnote and float membership goes to the tail too, so Enter in a footnote makes another block of it. A footnote whose anchor is deleted is an orphan, placed at the foot of the last page (or one page more if it does not fit); with duplicate anchors the first wins; nothing cascades and nothing is renumbered. Plain-text paste: the pasted blocks join the caret block's footnote or float but never copy the page break, page style or marks. Rejected: deleting a footnote with its anchor in one undo step (range delete and undo would have to learn about groups); a paste that carries nothing.

**L7-F2: a running-head slot is one style per slot, plain text with `{page}`/`{leftmark}`/`{rightmark}` fields.**
Rejected: runs or mixed styles in a slot.

**L7-F3: `\pageref` is resolved by `TexEditorControl` after layout.**
`ResolvePages` reads each label's page through `PageAt` and reloads the preview when a number changed, at most twice. Cost: a one-frame "??" per recompile that has a `\pageref`. Rejected: a page-field run filled inside `Paginate` (changes width mid-layout, needs a re-measure inside layout); seeding from the previous compile's page map (lag and history, the reason L5-F1 rejected latexmk-style).

**L7-F4: the incremental "settled" `Paginate` shortcut is off whenever the document has any footnote or float block (`inserts`).**
A full pass instead; only LaTeX output has them and the preview is rebuilt each recompile anyway. Rejected: teaching the shortcut to compare page reservations and an empty float queue.

**L7-F5: footnotes sit at the foot of the page's text area, as the slice said.**
Rejected: directly under the text, which is what LaTeX does under `\raggedbottom` (footmisc `[bottom]` is the LaTeX fix). Since L7f the foot sits above any bottom floats (L7f-F4).

**L7-F6 (agreed, built in L7f): float parameters as LaTeX-default constants.** Fractions and counts are constants, not read from `\topfraction` etc.
Rejected: reading `\topfraction` and the rest from the source into `<Page>`.

**L7f-F1 (user, recommended): a `t` float met mid-page goes to the current page's top if it fits, and `Paginate` rewinds.**
It reserves the top and re-lays the page's text from the first flow block that reaches that page. Footnotes reserved from that page on are rolled back; picture floats of the rewound blocks are dropped and re-registered. Floats already decided are skipped on the re-run, and a float set "here" is re-placed inline. Bounded by topnumber: at most 2 rewinds per page. Rejected: never the current page's top, always defer to the next page. Simpler, but it differs from LaTeX whenever a `[t]` float appears mid-page.

**L7f-F2 (user, recommended): a float inside a paragraph leaves the paragraph whole.**

Rejected: (a) keep the pre-L7f split of the paragraph at the float; (c) an anchor run in the text for an exact reference line, which needs a new `Run` attribute. Cost: a float written mid-paragraph in a long paragraph is placed relative to where the paragraph ends; the golden fixture needed blank lines around its floats.

**L7f-F3 (user, recommended): float separations are `<Page>` attributes written by lowering, like `FootnoteSkip`.**
The 12pt class differs (14 pt). Rejected: fixed 10pt constants in code.

**L7f-F4 (user, recommended): footnotes sit above bottom floats, LaTeX2e's default order.**

`<Cell RuleAbove RuleBelow TrimAbove TrimBelow>` and `<Column RuleLeft RuleRight>`, so row and column edits carry them for free. Rejected: a `<Rule From To Kind Trim>` per row boundary — LaTeX's exact shape, but column insert and delete must shift its indices. **L7g-F2 (user, recommended; R-F2): structural edits and rules.**

**L7g-F4 (user, recommended; M-F1): width-aware math is laid out again at the width, with a per-control cache for the current width only.**
The shared static `mathBoxes` cache stays width-free. Rejected: (b) recording each cell's glyph range and shifting — cheaper on resize, but `MathBox.Place` flattens the tree; (c) the width in the shared key (L6-F1's rejected option) — the cache grows per width.

**L7g-F5 (M-F2): tags follow amsmath's two stages; the user picked them mid-implementation.**
The approved option (a) put a tagged align 8 px left of LaTeX in `Tex.Amsmath`. Rejected: (a) always reserving tag + 1 em (off-centre against LaTeX); ignoring tags.

**L7g-F6 (asked mid-implementation): `TexLowering.MinColumn` goes from 24 to 28 px.**
`UIEngine.Collect` does not collect the children of a control under `detailCullSize` (12 px) in either dimension, so a `\tabcolsep`-padded one-letter cell (8.06 px of content in a 24 px column) drew no text. The user chose 28 px (12 + 2 · `\tabcolsep`), in lowering only. Rejected: changing the engine cull to both dimensions (a UI-wide perf heuristic); a 6 px across inset (text about 2 px off LaTeX in every column). Cost: one-letter columns are about 5 px wider than LaTeX's.

**L7g: amsmath's spacing, verified against `amsmath.dtx` (latex3/latex2e on GitHub, `\measure@` and `\multline@`).**
`align` with n pairs: the margins and the pair gaps are all (W − Σ columns) / (n + 1). `flalign`: no margins, gaps (W − Σ) / (n − 1), one pair falls back to `align`; gaps are at least `\minalignsep` (10 pt = 1 em), the margins then take (W − Σ − (n − 1) · sep) / 2, never negative. `multline`: the first row is `\multlinegap` (1 em) from the left, the last row `\multlinegap` from the right (with a tag, the tag and `\multlinetaggap` instead), middle rows centred. `alignat`, `aligned` and `gather` are unchanged.

**L7g: a table takes its alignment when the paragraph holding the tabular ends.**
That is TeX's rule, as for text: `{\centering\begin{tabular}…\end{tabular}}` followed by a blank line stays left.

**L7g supersedes L5-F2 and resolves L6-F1 partly.**
LaTeX tables are always `Borders="false"` with exact rules. L6-F1's "L7 could revisit" is done for top-level `align`/`flalign`/`multline`; L6-F2 partly (the tag room is now amsmath-like, a tag still never moves to its own line).

**L7e: footnotes stay in the flow lists but are not in the flow.**
Footnotes and floats stay in `children` and `document.blocks` in source order, so measuring, `Blocks()`, click-to-source and `blockLines` line up. The flow loops skip them (`Paginate`, `ArrangeCore`'s block loop, `MeasureCore`'s from/to count, `CollectChildren`'s binary search) and they are placed from `insertControls`; `blockTops` stays monotonic. `PageSpace` is used only when the document has inserts, so plain notes take the unchanged `PageBands.Push` path (one null check per line added in `TextRunControl.Paginate`). A footnote taller than its page's text area starts below the last text on that page (`PageSpace.TextEnd`) instead of rising above it — found by a test where a 405 px footnote on a 367 px text area overlapped the previous page. A LaTeX footnote's id is its sequence number, not the counter, so `\setcounter{footnote}` cannot make two footnotes share an id.

**L7d: marks follow TeX per page.**
`\leftmark` is the left half of the page's last mark, `\rightmark` the right half of its first mark, carried from earlier pages when the page has none. `\markright` keeps the left half. Heading marks follow the article/report/book one-sided rules; starred headings set none.

| Page style | article | report / book |
|---|---|---|
| headings | `\section` → `\markright{UPPER(num␣␣title)}` | `\chapter` → `\markright{CHAPTER n. TITLE}` |
| fancyhdr | `\section` → `\markboth{UPPER(num␣␣title)}{}`; `\subsection` → `\markright{num␣␣title}` | `\chapter` → `\markboth{CHAPTER n. TITLE}{}`; `\section` → `\markright{UPPER(num. title)}` |

**L7d: default page style and geometry.**
Plain for article and report, headings for book; `\maketitle`'s page takes plain. Every LaTeX preview now shows a page number in the foot. A head slot's bottom is `HeadSep` (25pt = 8.8 mm) above the text top; a foot slot's bottom is `FootSkip` (30pt ≈ 10.5 mm) below the text bottom; fancyhdr's `\headrulewidth` default 0.4pt is drawn under the head. The footnote rule is 0.4pt × 0.4 text width, 2.6pt above the first footnote; `\skip\footins` is 9/10/10.8pt by class size.
